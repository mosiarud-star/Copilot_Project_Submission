# Copilot_Project_Submission
For the learning purpose
Files:
1. Prompts Library.docx — This file’s purpose is to provide a step-by-step prompt framework for converting supply chain compliance issues into actionable insights, reports, action plans, and executive communication materials.
2. Task1_Email Summary.docx — Based on the Prompts Library.docx Task 1 and Prompts 1&2 execution result
3. Task1_Supply Chain Issues Review.docx — Based on the Prompts Library.docx Task 1 and Prompt 3 execution result
4. Task1_Supply Chain Report.xlsx — Based on the Prompts Library.docx Task 1 and Prompt 3 attachment
5. Task2_Action Plan.docx — Based on the Prompts Library.docx Task 2 and Prompt 2 execution result
6. Task2_Meeting Agenda.docx — Based on the Prompts Library.docx Task 2 and Prompt 1 execution result
7. Task2_Meeting Invite.ics — Based on the Prompts Library.docx Task 2 execution result
8. Task3_Supply Chain Issue Analysis Report.docx — Based on the Prompts Library.docx Task 3 execution result
9. Task4_Supply Chain Issue Compliance Report.pptx — Based on the Prompts Library.docx Task 3 execution result

Overview of each deliverables:
Task 1 — Review and structure the supply chain issue inputs
Purpose:
Build the initial understanding of the supply chain compliance issues from the prompt framework and validate the first outputs.
Deliverables:

Task1_Email Summary.docx
A summary generated from Task 1, Prompts 1 & 2.
Task1_Supply Chain Issues Review.docx
A structured written review of the identified supply chain issues.
Task1_Supply Chain Review.xlsx
The spreadsheet-based issue review/attachment supporting the written review.

Task 2 — Turn the issue review into an action plan and meeting package
Purpose:
Translate the findings from Task 1 into concrete actions and prepare stakeholder discussion materials.
Deliverables:

Task2_Meeting Agenda.docx
Agenda for the working session based on Task 2, Prompt 1.
Task2_Action Plan.docx
Action plan document based on Task 2, Prompt 2.
Task2_Meeting Invite.ics
Calendar invite created as part of Task 2.

Task 3 — Produce the supply chain issue analysis report
Purpose:
Develop a more complete analytical report using the outputs from the earlier tasks.
Deliverables:

Task3_Supply Chain Issue Analysis Report.docx
The main analysis report generated from Task 3 instructions.

Task 4 — Create the final compliance presentation
Purpose:
Convert the analysis into an executive-ready presentation summarizing the compliance issue and recommended actions.
Deliverables:

Task4_Supply Chain Issue Compliance Report.pptx
Final presentation output based on Task 4 instructions.

Overall flow
The document suggests this progression:

Prompts Library.docx defines the framework.
Task 1 creates the initial issue summary and review.
Task 2 creates the meeting agenda, action plan, and invite.
Task 3 develops the detailed analysis report.
Task 4 produces the final presentation.

Final output:
Task4_Supply Chain Issue Compliance Report.pptx
